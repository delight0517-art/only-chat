작성창에서 선택한 모델과 다음 요청의 라우팅 대상을 구분합니다. Antigravity 한도는 앱 실행 중 30분마다 조회하며, 실제 응답은 해당 계정의 실행 연결이 준비된 경우에만 가능합니다. 계정 한도는 제공자가 실제 수치를 제공할 때만 표시합니다.

새 계정 등록

환경 설정 & 패스키 보관함

새 채팅은 기본 폴더에서 시작하고, 다시 연 세션은 저장된 세션 폴더를 사용합니다. 이 표시는 작업 경로를 변경하지 않습니다.
승인 정책을 불러오는 중… 앱 도구는 호출별로 승인합니다. On Request에서 Codex는 요청마다 작업공간 쓰기 범위를 먼저 승인받고, Read Only에서는 화면·전원 변경 도구도 사용할 수 없습니다.
